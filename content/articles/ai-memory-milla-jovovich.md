### Types of Memory

**Episodic memory** allows an AI agent to recall specific past events or experiences, including the context in which they occurred. This is analogous to a human remembering "what happened yesterday" or "that specific conversation." For an AI, this means storing a sequence of states, actions, and observations. This type of memory is crucial for tasks requiring contextual understanding, such as maintaining coherent conversations or learning from specific training examples. Implementing [ai agent episodic memory](/articles/ai-agent-episodic-memory/) requires careful timestamping and contextual tagging of stored information. Understanding this component is key to building functional **ai memory**.

**Semantic memory** stores factual knowledge and general information about the world. It's the AI equivalent of knowing that Paris is the capital of France or that dogs bark. This knowledge is typically represented in a structured format, often independent of the specific event during which it was learned. This forms the knowledge base for AI reasoning and decision-making. Systems often use large language models and knowledge graphs to represent and access semantic memory, contributing to [semantic memory ai agents](/articles/semantic-memory-ai-agents/). This is a fundamental aspect of **ai memory systems**.

**Working memory**, also known as short-term memory, holds information that is currently being processed or is immediately relevant to the task at hand. It's a temporary storage space with limited capacity. Think of it as the AI's scratchpad for ongoing computations. This is essential for real-time processing and immediate response generation. However, the **context window limitations** of many models restrict the effective size of their working memory. Solutions often involve techniques like [context window limitations solutions](/articles/context-window-limitations-solutions/). Effective **ai memory** design must account for these constraints.

### Retrieval-Augmented Generation (RAG)

**Retrieval-Augmented Generation (RAG)** is a popular approach that combines the generative capabilities of large language models with an external knowledge retrieval system. Before generating a response, the AI retrieves relevant information from a knowledge base, which is then used to inform the generation process.

RAG significantly enhances the accuracy and relevance of AI responses by grounding them in factual data. This is distinct from purely parametric memory within the LLM itself. Comparing [rag vs agent memory](/articles/rag-vs-agent-memory/) reveals RAG's strength in knowledge retrieval. ### Vector Databases and Embeddings

**Vector databases** are specialized databases designed to store and query high-dimensional vectors, which are numerical representations of data (like text or images) generated by **embedding models**. These models convert complex data into dense vectors where semantic similarity is captured by vector proximity.

When an AI needs to recall information, it converts the query into a vector and searches the database for similar vectors. This allows for efficient retrieval of semantically related information, forming the backbone of many modern AI memory systems. class SimpleAgentMemory:
 def __init__(self):
 self.memory = {}
 self.turn_count = 0
 # Mock knowledge base for retrieval demonstration
 self.knowledge_base = {
 "weather": "I don't have access to real-time weather data.",
 "greeting": "I'm doing well, thank you!",
 "capabilities": "I can store and recall past conversations, and access general knowledge.",
 "Milla Jovovich": "Milla Jovovich is an actress known for her roles in science fiction films."
 }

 def add_memory(self, user_input, agent_response):
 self.turn_count += 1
 self.memory[self.turn_count] = {
 "user": user_input,
 "agent": agent_response
 }

 def retrieve_contextual_memory(self, last_n_turns=5):
 # Retrieve the last N turns, sorted by turn number
 start_turn = max(1, self.turn_count - last_n_turns + 1)
 context = []
 for i in range(start_turn, self.turn_count + 1):
 context.append(f"User: {self.memory[i]['user']}")
 context.append(f"Agent: {self.memory[i]['agent']}")
 return "\n".join(context)

 def respond_based_on_memory(self, user_input):
 # Simple keyword matching for demonstration
 response = "I'm not sure how to respond to that."
 user_input_lower = user_input.lower()

 if "hello" in user_input_lower or "hi" in user_input_lower:
 response = self.knowledge_base.get("greeting", "Hello there!")
 elif "weather" in user_input_lower:
 response = self.knowledge_base.get("weather", "I cannot provide weather updates.")
 elif "who is milla jovovich" in user_input_lower:
 response = self.knowledge_base.get("Milla Jovovich", "I don't have specific information on that.")
 elif "capabilities" in user_input_lower:
 response = self.knowledge_base.get("capabilities", "How can I assist you?")
 else:
 # If no specific keyword, try to use conversation history
 context = self.retrieve_contextual_memory(last_n_turns=3)
 if context:
 response = f"Based on our conversation history:\n{context}\nHow can I help further?"
 else:
 response = "I'm still learning. How can I assist you today?"
 return response

### What is the difference between RAG and traditional AI memory?
